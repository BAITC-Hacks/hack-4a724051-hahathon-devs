# Проверка объединённого MVP — 23 сентября 2026

Среда: Windows, Python 3.11, Node 24, Next.js 15.5.26. Браузер: Chromium в Codex. API и worker запущены отдельно, одна тестовая SQLite БД; `INTEGRATION_MODE=synthetic`, `LLM_ENABLED=false`, `UPLOADS_ENABLED=false`.

## Автоматически

- Backend: **210 passed, 16 skipped**. Пропущены проверки с настоящим PostgreSQL: нет запущенной службы и `TEST_DATABASE_URL`. Контракт чтения PostgreSQL и очистка ресурсов покрыты отдельными fake-pool тестами.
- `pip check`: нарушенных зависимостей нет.
- Proxy Next.js: 5 тестов — Origin, локальный Host, ограничения JSON/файлов, бинарная передача, cookie, заголовки сертификатов, неполное тело.
- TypeScript и production-сборка проверены.
- `npm audit`: 0 уязвимостей после обновления Next.js, PostCSS и Sharp.

## В браузере

- Главная с 12 разделами, каталог 65 демо-товаров; наличие сократило выборку до 59, применена сортировка по цене.
- Поиск `990100003_` дал одну позицию; карточка отобразила цену 1350 KZT, остаток 2, характеристики и ссылку на синтетический сертификат.
- Добавление в избранное отразилось в счётчике и сохранилось после перезагрузки. Сравнение показало два выбранных товара и их значения.
- Подборка 2 × 1350 = 2700 KZT: до подтверждения корзина пуста, после подтверждения — одна строка в количестве 2.
- Чат ответил по артикулу из того же каталога, затем на вопрос о доставке. Исправлен обнаруженный конфликт React-effect, блокировавший ввод после готового ответа. Повторный ввод проверен.
- Чат подготовил отдельное предложение `Купить 990100001_ 1 шт`; подтверждение добавило вторую строку. Ссылка открыла общую корзину с итогом 4050 KZT.
- После перезагрузки восстановились диалог, последнее предложение со статусом «Добавлено», ссылка и доступность ввода.
- Проверены главный экран и чат при мобильном размере 390 × 844.

## Что эти проверки не подтверждают

Не выполнялись платные OpenAI-запросы, импорт реального EKT и операции на живом PostgreSQL. Антивирус и загрузка файлов в браузере выключены; парсеры/карантин/ownership/vision-подготовка проверены автоматическими тестами с тестовым scanner. Для внешней приёмки нужны реальные ключи, scanner и источники данных. Демо-корзина не создаёт заказ EKT, аккаунт и оплата не реализованы.
