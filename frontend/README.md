# Витрина EKT — Next.js / TypeScript

Интерфейс использует только `/api/v1/*` своего origin. Next.js проксирует запросы в FastAPI через серверный `BACKEND_INTERNAL_URL`; cookie сессии — HttpOnly, изменения защищены Origin и CSRF. Секреты EKT/OpenAI хранятся в корневом `.env`, не в браузере.

## Локальный запуск (PowerShell, три терминала)

Если зависимости ещё не установлены, из корня репозитория:

```powershell
py -m venv backend/.venv
cd backend
.venv/Scripts/python.exe -m pip install -r requirements.lock -e ".[dev]"
cd ../frontend
npm ci
```

Скопируйте корневой `.env.example` в `.env`, **только если `.env` ещё нет**. В нём для первого запуска задайте `INTEGRATION_MODE=synthetic`, оставьте `LLM_ENABLED=false` и `UPLOADS_ENABLED=false`. API и worker должны читать один файл и один `LOCAL_DB_PATH`.

Терминал 1 — API:

```powershell
cd D:/hack-4a724051-hahathon-devs/backend
.venv/Scripts/python.exe -m uvicorn app.main:create_app --factory --host 127.0.0.1 --port 8000 --no-proxy-headers
```

Терминал 2 — обработчик сообщений:

```powershell
cd D:/hack-4a724051-hahathon-devs/backend
.venv/Scripts/python.exe -m app.worker
```

Терминал 3 — интерфейс:

```powershell
cd D:/hack-4a724051-hahathon-devs/frontend
npm run dev -- --hostname 127.0.0.1
```

Откройте http://127.0.0.1:3000. Документация backend: http://127.0.0.1:8000/docs. Без worker сообщения останутся в очереди. Для production-сборки интерфейса: `npm run build`, затем `npm run start -- --hostname 127.0.0.1` (не одновременно с dev на том же порту).

## Проверка функций

1. Главная → категория → подкатегория. Сравните выдачу, счётчики, переключите плитку/список и страницу.
2. Ищите по названию или точному артикулу из карточки; задайте производителя, диапазон цены, «Только в наличии» и сортировку. Нулевая выдача в частичном каталоге не означает отсутствие товара на EKT.
3. Откройте карточку: цена, остаток, характеристики и сертификаты поступают из backend. Избранное и сравнение сохраняются только в этом браузере.
4. Нажмите «В подборку», выберите количество и запросите предложение. Проверьте состав и сумму; корзина изменяется только после подтверждения. Повтор подтверждения не добавляет товары ещё раз. Это демо-корзина без оплаты и передачи заказа EKT.
5. Откройте помощника. Отправьте артикул, затем «характеристики», «есть аналог?» или «условия доставки». Попробуйте русский, казахский, английский. Для покупки: «Купить <артикул> 2 шт», затем проверьте и подтвердите предложение. Обновите страницу и откройте чат — история и текущая задача восстанавливаются в пределах сессии.
6. Проверьте остановку задачи и восстановление после временной недоступности API. При неопределённом результате интерфейс повторяет тот же ключ операции; не нужно создавать дубликаты.
7. Для файлов включите настоящий scanner и `UPLOADS_ENABLED` по `docs/assistant-testing.md`. Скрепка принимает PDF, DOCX, XLSX, JPG, PNG, TXT, CSV: до 3 файлов по 10 МиБ. Непроверенные файлы нельзя отправить на анализ. Для фото/сканов нужен OpenAI и отдельное согласие на внешнюю обработку.

## Каталог и границы

`synthetic`: SQLite автоматически получает тестовые товары один раз при пустой таблице; изменения сохраняются между перезапусками. `catalog_db`: PostgreSQL участника 1, миграции и импорт описаны в `docs/data-and-db.md`. Оба режима используют единые DTO и маршруты `/catalog/categories`, `/catalog/products`, `/products/{id}`. Ассистент и корзина читают тот же источник.

Витрина сохраняет структуру EKT (12 разделов, поиск, фильтры, карточки, сравнение, избранное, корзина). Авторизация EKT/B2B и контакты открывают официальный сайт. Собственного аккаунта, оплаты, реального оформления заказа и полного зеркала каталога здесь пока нет. Фильтры технических характеристик из полного EKT требуют соответствующих нормализованных данных и отдельных facets API; текущие фильтры — категория, бренд, цена, наличие.

Реальные OpenAI-вызовы требуют ключа и разрешения оператора. Подробности: `docs/assistant-testing.md`. Независимые части кода: `src/lib/api.ts` — DTO/транспорт; `src/app/api/v1/[...path]/route.ts` — серверный proxy; `src/components/storefront/` — витрина; `src/components/assistant-chat.tsx` — чат; `src/app/page.tsx` — координация состояния.

## Автоматические проверки

```powershell
# frontend
npm run typecheck
npm run build
# backend (из каталога backend)
.venv/Scripts/python.exe -m pytest
```

PostgreSQL-тесты требуют отдельной одноразовой `TEST_DATABASE_URL`: они очищают схему public. Не указывайте рабочую БД.
