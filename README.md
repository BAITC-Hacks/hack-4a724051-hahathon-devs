# hack-4a724051-hahathon-devs

Команда Hahathon Devs, HACKALEM AI 2026.

Кейс: ИИ-ассистент для чата на сайте ekt.kz (ТОО "Электрокомплект").

Чат-консультант для интернет-магазина электротехники. Клиент спрашивает про товар, наличие, аналог или условия покупки и сразу получает ответ по данным каталога. Добавить товар в корзину можно только после явного подтверждения, количество не больше остатка, после добавления клиент получает ссылку на корзину.

## Обязательные требования кейса

- [x] Наличие, характеристики и сертификат по артикулу
- [x] Аналоги для позиций с нулевым остатком, с обоснованием
- [x] Ответы на вопросы об условиях покупки
- [x] Корзина меняется только после явного подтверждения, количество не больше остатка
- [x] Ссылка на актуальную корзину после добавления

Как проверить каждый пункт, описано ниже в разделе «Сценарий проверки».

## Быстрый запуск (демо, без ключей)

Нужны Python и Node.js из таблицы выше. Понадобятся три терминала: API, обработчик сообщений (worker) и интерфейс.

**1. Установка и настройки** (один раз, из корня репозитория)

macOS / Linux:

```bash
python3 -m venv backend/.venv
backend/.venv/bin/pip install -r backend/requirements.lock -e "./backend[dev]"
cp .env.example .env
sed -i.bak 's/^INTEGRATION_MODE=.*/INTEGRATION_MODE=synthetic/' .env
cd frontend && npm ci && cd ..
```

Windows (PowerShell):

```powershell
py -m venv backend/.venv
backend/.venv/Scripts/python.exe -m pip install -r backend/requirements.lock -e "./backend[dev]"
Copy-Item .env.example .env
(Get-Content .env) -replace '^INTEGRATION_MODE=.*', 'INTEGRATION_MODE=synthetic' | Set-Content .env
cd frontend; npm ci; cd ..
```

В `.env` должно получиться `INTEGRATION_MODE=synthetic`. Остальное оставьте как есть: модель и загрузка файлов выключены, ключи не нужны.

**2. Терминал 1: API**

```bash
cd backend
.venv/bin/python -m uvicorn app.main:create_app --factory --host 127.0.0.1 --port 8000 --no-proxy-headers
```

На Windows вместо `.venv/bin/python` пишите `.venv/Scripts/python.exe`. Проверка: http://127.0.0.1:8000/health/ready, документация API: http://127.0.0.1:8000/docs.

**3. Терминал 2: worker** (без него сообщения чата останутся в очереди)

```bash
cd backend
.venv/bin/python -m app.worker
```

**4. Терминал 3: интерфейс**

```bash
cd frontend
npm run dev
```

Откройте http://127.0.0.1:3000. Если порты 3000 или 8000 заняты, смотрите раздел «Частые проблемы».

## Сценарий проверки

Данные демонстрационные, чтобы проверять можно было без доступа к реальному складу. Артикулы ниже есть в демо-каталоге.

1. **Наличие, характеристики, сертификат.** В чате («Помощник по подбору») отправьте `990100003_`. Придёт «Автоматический выключатель ВА47-29 1P 20А C 4,5кА IEK» с ценой, остатком по складам, характеристиками и ссылкой на сертификат (PDF-заглушка с пометкой, что он синтетический).
2. **Аналог при нулевом остатке.** Отправьте `990100015_` (Legrand RX3 1P 16А, остаток 0). В ответе будет аналог в наличии и объяснение: что совпадает (ток, полюса, характеристика, отключающая способность) и чем он отличается. Ещё примеры: `990100050_` (дифавтомат), `990100055_` (розетка).
3. **Условия покупки.** Спросите «условия доставки», «как оплатить», «есть рассрочка?», «минимальная партия». Ответы взяты со страниц ekt.kz, источники указаны.
4. **Корзина только после подтверждения.** Отправьте «Купить 990100001_ 2 шт». Придёт предложение с составом и суммой, корзина пока не меняется. Подтвердите кнопкой или ответом «да, добавь». Повторное подтверждение ничего не добавит, больше остатка добавить нельзя.
5. **Ссылка на корзину.** После подтверждения в ответе есть ссылка `/api/v1/cart/view`, по ней видно актуальное состояние корзины текущей сессии.

Витрина: 12 разделов, как на ekt.kz, поиск, фильтры по бренду, цене и наличию, карточки с фото. Чат понимает русский, казахский и английский.

## Данные

- `data/synthetic/ekt_products.json`: демо-каталог, 281 товар в формате ответа `/api/products/detail` ekt.kz. 68 товаров полностью синтетические, у них свои векторные иллюстрации. Остальные 213 взяты из API ekt.kz: название, фото (ссылкой на ekt.kz), раздел и характеристики. У всех товаров ID, артикулы, штрихкоды, остатки и цены демонстрационные. Пересборка: `python3 data/synthetic/generate.py`, новая выборка с ekt.kz: `python3 data/synthetic/fetch_ekt_selection.py` (нужен доступ к API в `.env`).
- `data/curated/purchase_terms.json`: условия оплаты, доставки, возврата и т.д. с публичных страниц ekt.kz, у каждой темы указан источник.
- `data/curated/category_labels.json`: русские названия подразделов каталога.

Реальный API каталога ekt.kz подключается через `INTEGRATION_MODE=catalog_db` и PostgreSQL, см. [docs/data-and-db.md](docs/data-and-db.md). Логин и пароль API в репозитории не хранятся, только в локальном `.env`.

## Архитектура

```
браузер ── Next.js (витрина, чат) ── прокси /api/v1 ── FastAPI ── worker
                                                          │          │
                                               каталог, поиск,   ассистент:
                                               аналоги, корзина  ответы из фактов каталога,
                                                          │      модель по желанию
                                               SQLite (демо) или PostgreSQL
```

- Цены, остатки, ссылки и состав корзины берутся только с сервера из данных каталога. Модель не может их придумать и не может сама изменить корзину.
- Подтверждение корзины привязано к сессии, версии предложения и сроку действия. Перед добавлением цена и остаток проверяются заново.
- Ключи EKT и LLM есть только у backend, браузер их не получает.

Код backend в `backend/app/modules`: `catalog` (модель товара и правила проверки данных), `search` (поиск и аналоги), `knowledge` (условия покупки), `actions` (предложение и подтверждение корзины), `assistant` (обработка сообщений, план от модели, ответы из фактов), `chat`, `documents` (разбор файлов). Подробнее: [docs/architecture.md](docs/architecture.md), [docs/backend-integration.md](docs/backend-integration.md), HTTP-контракт [docs/openapi.json](docs/openapi.json), витрина [frontend/README.md](frontend/README.md).

## Частые проблемы

- **Каталог пустой или «интеграция недоступна».** В `.env` не выставлен `INTEGRATION_MODE=synthetic`, или API и worker запущены с разными настройками. Поправьте `.env` и перезапустите оба процесса.
- **Сообщения в чате висят в очереди.** Не запущен worker (терминал 2).
- **Порт 8000 или 3000 занят.** Запустите API на другом порту (`--port 8010`), интерфейс командой `BACKEND_INTERNAL_URL=http://127.0.0.1:8010 npm run dev -- -p 3010` и добавьте в `.env` строку `ALLOWED_ORIGINS=["http://127.0.0.1:3010","http://localhost:3010"]`.
- **После обновления данных в интерфейсе старые товары.** Демо-каталог в SQLite заполняется только при пустой базе. Остановите API и worker, удалите `backend/var/participant2.sqlite3` и запустите их снова.
