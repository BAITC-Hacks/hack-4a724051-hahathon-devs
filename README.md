# EKT — каталог и ИИ-консультант

Hackathon team repository for Hahathon Devs.

Проектируем улучшенный MVP для ekt.kz: поиск товаров, проверяемые ответы, аналоги, обработка спецификаций и добавление в корзину после явного подтверждения покупателя.

## Текущее состояние

Подготовлены исследование, архитектура и конфигурационные шаблоны. Backend, frontend и описанные собственные API пока не реализованы. Внешний API каталога проверен на чтение; API реальной корзины не предоставлен. Первая реализация использует явно обозначенную демонстрационную корзину.

## Секреты и окружение

Скопируйте `.env.example` в `.env` локально:

```powershell
Copy-Item .env.example .env
```

Перед копированием убедитесь, что собственного `.env` ещё нет. Заполните `EKT_API_USER`, `EKT_API_PASSWORD`, а при подключении провайдера — `LLM_API_KEY`. Эти значения предназначены только для backend и не должны попадать в Git, frontend, логи или запросы к модели.

`.env.example` содержит пустые значения и хранится в Git; `.env` и его локальные варианты исключены. Lock-файлы зависимостей нужно коммитить. Наличие ключа не должно автоматически включать платные вызовы: механизм активации и обязательные лимиты описаны в архитектуре.

Инструкции запуска приложения будут добавлены с реализацией. Пока запускать приложение или подключать реальные ключи не требуется.
